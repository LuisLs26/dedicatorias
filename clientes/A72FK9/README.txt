==================================================
PERSONALIZAR ESTE REGALO DIGITAL - DEDICA
==================================================

¡Felicidades por tu regalo digital interactivo!
Este proyecto es 100% autónomo y no requiere servidores complejos ni conocimientos de programación.

PASOS PARA PERSONALIZAR:
--------------------------------------------------
1. Abre el archivo "config.js" con cualquier editor de texto (Bloc de Notas, VS Code, etc.).
2. Cambia el nombre del destinatario y remitente.
3. Edita los mensajes y dedicatorias a tu gusto.
4. Para cambiar las fotos:
   - Coloca tus imágenes dentro de la carpeta "assets/images/".
   - Asegúrate de que el nombre en config.js coincida (ej: "./assets/images/foto1.jpg").
5. Si deseas música personalizada:
   - Coloca tu archivo MP3 en "assets/audio/".
   - Escribe la ruta en config.js (ej: musica: "./assets/audio/cancion.mp3").
   - Si dejas musica en null, sonará la melodía ambiental armónica por defecto.
6. Abre "index.html" en cualquier navegador (Chrome, Safari, Edge) para ver el resultado.

CÓMO COMPARTIR EN LÍNEA:
--------------------------------------------------
- Puedes subir esta carpeta a servicios gratuitos como GitHub Pages, Cloudflare Pages, Netlify o Vercel.
- Al publicar, obtendrás un enlace web directo para enviar por WhatsApp, TikTok o Instagram.

¡Gracias por elegir DEDICA!
